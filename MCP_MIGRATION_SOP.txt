OVERVIEW
--------
This document provides step-by-step instructions for migrating the Harris
HawkEye MCP to a company server environment.

WHAT YOU'RE MIGRATING
---------------------
- Harris HawkEye MCP (105 tools, 6 prompts)
- 11,800+ Detection Rules (Sigma, Splunk ESCU, Elastic, KQL)
- MITRE ATT&CK Database (835 techniques, 187 groups, 787 software)
- Knowledge Graph System
- Claude Code Skills (7) — at ~/.claude/skills/ on source machine (separate copy step)
- CLAUDE.md Workflow Guide

TOTAL SIZE: ~4.5 GB (project) + ~50 MB (skills)

================================================================================
                         PRE-REQUISITES (TARGET SERVER)
================================================================================

1. Node.js v18 or higher
   - Check: node --version
   - Download: https://nodejs.org/

2. npm (comes with Node.js)
   - Check: npm --version

3. Claude Desktop installed
   - Download: https://claude.ai/download

4. Internet access (one-time, for npm install)
   - If no internet, see OFFLINE INSTALLATION section below

================================================================================
                         PHASE 1: COPY FILES
================================================================================

OPTION A: USB/Hard Drive Transfer
---------------------------------
1. Copy entire folder:
   FROM: C:\Users\harsh\OneDrive\Desktop\security-detections-mcp
   TO:   [USB DRIVE]\security-detections-mcp

2. On target server, copy to desired location:
   RECOMMENDED: C:\Tools\security-detections-mcp

OPTION B: Network Transfer
--------------------------
1. Zip the folder (exclude node_modules to reduce size):

2. Transfer via network share, SFTP, or cloud storage

3. Extract on target server

================================================================================
                         PHASE 2: INSTALL & BUILD
================================================================================

Open PowerShell/Command Prompt on target server:

STEP 1: Navigate to folder
--------------------------
cd C:\Tools\security-detections-mcp

STEP 2: Install dependencies
----------------------------
npm install

Expected output: "added XXX packages"
Time: 1-3 minutes (depends on network)

STEP 3: Build TypeScript
------------------------
npm run build

Expected output: No errors, creates/updates dist\ folder
Time: ~30 seconds

STEP 4: Verify installation
---------------------------
node dist\index.js

Expected output:
  [security-detections-mcp] Starting Enhanced Security Detections MCP...
  [db] Initializing database...
  [security-detections-mcp] Auto-indexing detections...
  [security-detections-mcp] Indexed XXXX detections
  [security-detections-mcp] Indexing MITRE ATT&CK...
  [tools] Registry initialized with 122 tools

Press Ctrl+C to stop after verification.

                         PHASE 3: CONFIGURE CLAUDE DESKTOP
================================================================================

STEP 1: Locate config file
--------------------------
Windows: %APPDATA%\Claude\claude_desktop_config.json
Mac:     ~/Library/Application Support/Claude/claude_desktop_config.json

STEP 2: Edit configuration
--------------------------
Open the file in a text editor and add/replace with:

{
  "mcpServers": {
    "harris-hawkeye": {
      "command": "node",
      "args": ["C:\\Tools\\security-detections-mcp\\dist\\index.js"],
      "env": {
        "SIGMA_PATHS": "C:\\Tools\\security-detections-mcp\\rules\\sigma\\rules",
        "SPLUNK_PATHS": "C:\\Tools\\security-detections-mcp\\rules\\splunk\\detections",
        "ELASTIC_PATHS": "C:\\Tools\\security-detections-mcp\\rules\\elastic\\rules",
        "KQL_PATHS": "C:\\Tools\\security-detections-mcp\\rules\\sentinel\\Hunting Queries",
        "OTX_API_KEY": "YOUR_OTX_API_KEY_HERE"
      }
    }
  }
}

IMPORTANT: 
- Replace all paths with actual install location
- Use double backslashes (\\) in Windows paths
- OTX_API_KEY is optional (8 OTX tools won't work without it)

================================================================================
                         TROUBLESHOOTING
================================================================================

ISSUE: "npm install" fails
--------------------------
Cause: Network/proxy issues
Solution: 
  - Check proxy settings: npm config set proxy http://proxy:port
  - Or use offline installation method

ISSUE: "npm run build" fails
----------------------------
Cause: TypeScript errors or missing dependencies
Solution:
  - Delete node_modules and package-lock.json
  - Run: npm install
  - Run: npm run build

ISSUE: MCP not showing in Claude Desktop
----------------------------------------
Cause: Config file errors
Solution:
  - Verify JSON syntax (no trailing commas)
  - Verify all paths exist
  - Restart Claude Desktop completely
  - Check Settings > Developer for error messages

ISSUE: "Module not found" errors
--------------------------------
Cause: Incomplete npm install
Solution:
  - Run: npm install
  - Run: npm run build

ISSUE: Database errors / no detections found
--------------------------------------------
Cause: Corrupt or missing database
Solution:
  - Delete database file:
    Windows: del %USERPROFILE%\.cache\security-detections-mcp\detections.db
  - Restart MCP (will auto-reindex)

ISSUE: MITRE ATT&CK data not available
--------------------------------------
Cause: STIX file not found
Solution:
  - Verify file exists: rules\elastic\detection_rules\etc\attack-v18.1.0.json.gz
  - If missing, the MITRE tools will be limited

ISSUE: OTX tools not working
----------------------------
Cause: Missing or invalid API key
Solution:
  - Get free API key from: https://otx.alienvault.com
  - Add to OTX_API_KEY in config
